## 安全提醒

- Access Token / Session JSON 是临时登录凭证，只提交到可信的充值页面，不要发到群聊、论坛或评论区。
- 正规充值不需要你的 ChatGPT 密码、邮箱密码或短信验证码。
- 一个账号只给自己用。多人共用、多地同时登录是触发风控的常见原因。
