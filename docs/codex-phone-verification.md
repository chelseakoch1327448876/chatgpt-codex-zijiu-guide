## 为什么 ChatGPT 能用，Codex 却要手机号？

按 OpenAI 帮助中心的说明，注册和普通使用 ChatGPT 一般不需要手机号，但在 ChatGPT 桌面应用里使用 Codex 时可能被要求验证；在开发者平台生成第一把 API Key 时也必须验证。Codex 能直接读写代码、执行命令，所以多了一道验证。

## 哪些号码能用

| 号码类型 | 能否通过 | 说明 |
| --- | --- | --- |
| 支持地区的实体手机卡（美国、英国、日本、新加坡等） | 可以 | 短信接收，最稳定 |
| WhatsApp 支持国家的号码 | 可以 | 印度、印尼、越南、马来西亚、土耳其、沙特、阿联酋等可选 WhatsApp |
| 中国大陆 +86 / 香港 +852 | 通常不行 | 不在 OpenAI 服务支持范围内 |
| 固定电话 | 不行 | 官方明确不支持 |
| VoIP 虚拟号、Google Voice | 不行 | 官方称此类号码滥用比例高 |
| 高资费号码 | 不行 | 同上 |

验证码只通过短信或 WhatsApp 发送，不会发邮件，也不会打电话。以验证页实际选项为准。

## 验证步骤

1. **核对账号**：chatgpt.com 左下角头像里的邮箱与 Codex 登录账号一致，订阅已生效。
2. **选对区号**：默认是美国 +1，其他国家号码先切换区号，号码前不要重复加区号。
3. **选接收方式**：有 WhatsApp 选项才可选，否则是短信。
4. **填最新验证码**：重发过的话只有最后一条有效。
5. **命令行用户**：`codex login` 后浏览器可能跳到「Confirm phone number」页，处理方式相同，完成后回终端即可。

## 报错排查

| 现象 | 常见原因 | 处理办法 |
| --- | --- | --- |
| 提示号码不受支持 | 固话、VoIP，或地区不支持 | 换支持地区的实体手机号 |
| 提示「请使用其他号码」 | 号码已被其他账号用过或被风控 | 保持同一账号登录，换另一个你能控制的号码 |
| 短信迟迟不来 | 区号选错、运营商拦截、实际发的是 WhatsApp | 核对后等 1–2 分钟再重发 |
| 尝试次数过多 | 短时间重发太多次 | 按提示的等待时间后再试 |
| 要求验证已停用的旧号码 | 账号曾绑定该号码，Codex 沿用 | 带完整报错截图联系 OpenAI 支持，说明是 Codex 登录场景 |
| 企业版 SSO 也要手机号 | 非预期的验证请求 | 把确切报错发给官方支持 |

## 国内用户没有可用号码怎么办

按长期稳定性从高到低：

1. **办一张支持地区的实体手机卡**（可长期保号的英国、美国、新加坡等预付费卡），号码归自己，以后再验证也能收码。
2. **使用 Codex 验证服务**：[czgptai.com](https://www.czgptai.com/) 提供 Codex 验证服务，在服务页面拿到号码并直接查看验证码。注意：号码租期结束后不归你所有，以后若再次要求验证同一号码，可能收不到码。
3. **请海外亲友帮忙接收**：可临时解决，同样有以后无法再次验证的风险。

不建议用公开的免费接码网站：号码大多被大量账号用过或属于 VoIP，几乎都会被拒，而且任何人都能看到你的验证码。

## FAQ

**已经充值了 Plus / Pro，为什么还要手机号验证？**
验证和订阅是两件事，订阅不免除验证。完成验证后即可使用订阅内的 Codex 额度，不用重新购买。

**+86 手机号能验证 Codex 吗？**
通常不能，需要支持地区的实体手机号。

**验证码能发到邮箱吗？**
不能，只支持短信或 WhatsApp。

**Google Voice 或虚拟号码可以吗？**
不可以，官方不支持固话、VoIP、Google Voice 和高资费号码。

**要求验证旧号码，但号码已停用怎么办？**
带完整报错截图联系 OpenAI 支持，说明问题只出现在 Codex 登录。不要为此重新购买订阅。
